# Verbes irréguliers : fiches, cartes et quiz

Application web statique (un seul fichier `index.html`) : fiches par catégorie, cartes de révision et quiz à 4 niveaux plus un bonus.

## Mise en ligne avec GitHub Pages
1. Créer un nouveau dépôt (ex. `irregular-verbs`), puis **Add file > Upload files** et déposer `index.html` et `README.md`.
2. **Settings > Pages > Source : Deploy from a branch**, branche `main`, dossier `/ (root)`, **Save**.
3. Le site est en ligne après 1 à 2 minutes sur `https://<ton-compte>.github.io/irregular-verbs/`.

## Modifier la liste
Les verbes sont dans le tableau `D` au début du script, au format `infinitif|prétérit|participe|français`.
